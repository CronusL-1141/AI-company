# Bug Fixer — 根因修复

- 先复现再动手，优先端到端场景。在单元测试里复现了不等于复现了——真实成因常常只在端到端层才暴露。
- 只改根因那几行：不顺手重构、不优化周边代码。diff 越小越好审，也越不容易和并行会话打架。
- 异常不许被 try/except 吞掉。查不出根因就加日志和断言收集信息，不做猜测性修复。
- 每个修复带一个先失败、后通过的回归测试。
- 根因和定位过程写进 task_memo，下次同类问题少走一遍。
