# Codex 套餐可用量

本说明对应开发候选，不代表共享 API、MCP 或 Dashboard 已升级。

## 页面上的两个数字

- **预计套餐可用量（美元）**：将绑定后的本机逐响应用量按模型计价，用同期美元增量与额度百分点变化估算总容量，标记为“本机样本估算”。这是 Standard API 等值，不是订阅实付、现金余额或官方固定容量。
- **已使用百分比**：原生 Codex 额度接口返回的已用比例，不是上下文窗口占用。

例如，本周期最早采样为 20%，最新为 21%，两者之间已知逐响应计价累计 $1.11，预计总容量就是 $111。每次与固定周期锚点比较，不是仅计算相邻两次差值；缺失部分仅在预测公式中贡献 0。它反映当前本机工作负载的样本比例；同一账号在其它设备同时使用时，未采集的活动会影响外推结果。内置有来源与校验时间的价格目录，无需手动导入请求日志或接入真实账单。

## 模型、缓存与长上下文计价

复用 `pricing.quote_requests`，不另造分词器或模型网关。实际模型来自响应记录或可核对的同一回合元数据。每条请求分别按 `(input - cached - cache_write) × 普通输入价 + cached × 缓存读取价 + cache_write × 缓存写入价 + output × 输出价` 计价，费率单位为每百万 Token；输出已含 reasoning 和不可见结构 Token，不重复加算。

上下文档位按每条请求的完整输入（包含缓存）决定，不能把多条短请求相加后套长上下文价。以当前 Astra 为例：不超过 272,000 输入用短档，超过则整次请求用长档；长档输入和缓存价格是短档两倍、输出是 1.5 倍，不是全部统一翻倍。缓存写入价替代该部分普通输入价，不是叠加费。[官方模型规则](https://developers.openai.com/api/docs/models/gpt-6-astra)、[价格表](https://developers.openai.com/api/docs/pricing)。

本地日志有明确 `service_tier` 时使用 `logged_tier`；其中 `fast` 直接选目录中的 Fast 费率（已是 Standard 的两倍），不再额外乘倍数。缺少档位的旧记录回退 `standard_equivalent`，不能把速度选项或 credits 倍率猜成 Fast 账单。模型 Token 等值不包含另收费的托管工具、存储、图像或音视频服务。未知模型须补有来源的费率；原始请求和报价仍保留未知状态，不伪造零费率。套餐预测使用明确的 `prediction_basis=cycle_anchor_missing_zero`：已知金额继续累计，缺失贡献 0，与原始账务完整性分开。

## 使用

1. 在本机 Codex 登录自己的 ChatGPT 账号，打开 `/usage/accounts`，连接账号。
2. 当前账号核验成功后默认开启预测。在“账号设置与监控”中设置别名或采样间隔，新配置支持 30 秒至 30 分钟，默认周期为 30 分钟；本机当前登录源一次预测一个账号。
3. OS API 运行时自动采样，无需模型被唤醒，也不要求浏览器保持打开。明确暂停只停止预测，不停止独立用量记录器，服务重启保留该选择。

升级不会缩短已保存的旧周期。旧版超过 30 分钟、最长 24 小时的设置仍可读取并按原周期运行，也可暂停；再次启用时需明确选择新范围内的周期。API 的 `GET /api/account-usage/{account_key}/monitor` 会如实返回旧周期；`PUT` 显式填写的 `interval_ms` 只接受整数 `30000..1800000`。暂停可只发送 `{"enabled": false}`，省略周期以保留原值；启用超过 30 分钟的旧周期若未明确提供新周期，会返回 `409`，不会自动缩短。

首次可信账号观测建立本周期锚点，不把当前登录身份套到过去的未知记录。采集可以增量读取，预测始终从本周期最早观测累计到最新；只有已用百分比下降或官方重置周期变化才更换周期锚点，来源重绑、缺失或价格目录变化不清除周期记录。已用百分点增量大于 0 即计算，1% 也有效；已知金额为 0 时允许显示 $0.00。旧原始快照保持不变，按账号、额度桶与窗口隔离；窗口过期不拿旧百分比当当前值。

### 手动重置统计起点

Codex 有效窗口卡片的“重置统计起点”按钮，以服务器最新一次已保存采样为新的统计起点。
按钮不会新采样、删除用量记录或改变监控间隔；只影响点击的账号与窗口，并跨重启保存。
重置后显示“采样中”，后续按新锚点累计算金额与百分点变化，不沿用重置前的预估。
额度自然下降或官方周期变化后，旧手动起点失效。无可用采样或窗口已过期时不会创建假锚点。
接口为 `POST /api/account-usage/{account_key}/plan-anchor/reset`，请求只指定额度桶和窗口时长，
实际采样 ID 与时间由服务器选择；同一最新点重复操作保持幂等。

## 数据与监控

新链路使用 `account/read` 和 `account/rateLimits/read` 核对前后账号，Token 改读 `CODEX_HOME`（默认 `~/.codex`）内 `sessions` 与 `archived_sessions` 的本地 JSONL，不再请求延迟的 `account/usage/read` 汇总。接受明确 `model_provider=openai` 或已持久化 `thread_settings.model_provider_id=openai` 的活动。历史提供方别名只有在本机稳定配置明确指向官方 ChatGPT Codex 地址、要求 OpenAI 授权且强制 ChatGPT 登录，没有自定义认证来源，并有配置变更后的会话或提供方记录时才可识别；第三方网关与未知来源不混入。此映射依据本机配置，不是逐请求远端身份的证明。

美元链路按 `token_usage_record` 的唯一 response ID 去重；旧 `token_count` 只保留 Token 诊断，不把无法定位单次请求、模型和上下文档位的累计差分套价。输入包含缓存，只加一次输出，不重复加 reasoning；父子继承、重复快照、归档副本不重复计价。读取在异步工作线程中进行，有时间、字节、文件数和 10,000 条响应上限，报价按 1,000 条分片且同一目录对象；损坏、冲突、超限或未完成尾行会打断美元样本，不冒充成功的零。

账号、源目录、登录元数据或有效提供方路由/授权语义改变时重建绑定。`auth.json` 只读 stat，不读正文；`config.toml` 的格式、MCP 配置或无关参数改写不改变跨轮来源标识。提供方配置的原始生效证据时间随本机快照持久保存，同语义重写不以最新 mtime 覆盖它；旧会话仍须有晚于该证据的原生提供方记录，不能借当前别名回认过去的网关请求。两文件的 inode/size/mtime/ctime 仍作单次采样前后的竞态围栏，读取中发生变化则丢弃本机增量。不输出或保存完整配置及凭据。识别规则和别名摘要也属于来源标识，规则升级后重新建立零基线，不把新解释回填到旧样本。累计样本与绑定起点随快照持久保存，同源 API 重启可继续原区间。旧 `codex_account_activity` 汇总快照原样保留，仍返回 `activity_coverage_unknown`，不会混进新的 `codex_local_logs` 样本。独立模型额度桶不套用主账号总活动量。

逐请求报价保留当时的价格目录 hash 和计价模式，不用今天的价格回填旧 Token；换价或来源变化不会清除本周期预测锚点。Spark 响应从主桶金额中排除，独立桶未能归属时保留百分比但不套主桶预测。暂停或改设置使在途预测采样失效；所有 API worker 与手动采样共用持久租约。额度、原有 Token 与独立美元凭据同事务保存，过期执行器不能写回。服务恢复不补造停机期间的额度观测。切换登录账号或授权不可用会暂停旧绑定，网络失败按配置间隔重试。

独立用量记录器在 API 生命周期内默认运行，递增文件游标而非以预测时间窗口判断是否保存。`codex_usage_observations` 保存白名单使用事实，`codex_usage_source_cursors` 保存已提交位置；缺模型、未知 provider、legacy 用量仍可留存。完整行和游标同事务写入，半行完成或旧时间记录迟到后再保存，暂停预测不会停止记录。事实不包含对话正文或凭据，不自动认领未知账号。当前独立记录层先解决保存问题，预测的原生日志输入与记录台账投影分开接线，不把“已经入库”说成“全部历史已经可计价”。首次入库前已被删除的来源无法恢复。详见[设计](../../../docs/codex-usage-persistence-design.md)。

## 安装与隔离

macOS 默认使用 Desktop 内置 `/Applications/ChatGPT.app/Contents/Resources/codex`；其它安装可显式配置 `AITEAM_CODEX_BINARY` 绝对路径。OS 不复制凭据、邮箱或原始账号 ID，只保存单向账号摘要与用户别名；不发起登录、切号或授权刷新。只读采样子进程有时间上限并在结束时回收。

美元证据新增独立 `account_plan_price_snapshots` 表，与原 `account_plan_snapshots` 按原生额度 snapshot ID 关联；旧 Token 类型与记录原样保留，不嵌金额，不删除历史样本。已有价格 API、批次 API 与 `aiteam account-usage export` CLI 独立保留，套餐页面不要求价格/JSON 导入流程。

验证使用独立 SQLite 与临时 Dashboard 构建；没有更改共享数据库或 Claude 端。部署需将源码、API 与页面同批更新并另获授权。没有个人 heartbeat、模型定时唤醒或后台自动抓价。
