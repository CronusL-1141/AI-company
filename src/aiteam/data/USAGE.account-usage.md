# Codex 套餐可用量

本说明对应开发候选，不代表共享 API、MCP 或 Dashboard 已升级。

## 页面上的两个数字

- **预计套餐可用量**：根据绑定后本机 OpenAI 会话的 Token 增量与同期额度变化估算总容量，标记为“本机样本估算”，不是跨设备全账号总量或剩余容量。
- **已使用百分比**：原生 Codex 额度接口返回的已用比例，不是上下文窗口占用。

例如，两个采样时刻之间本机日志增加 100 万 Token、已用比例从 20% 变为 25%，预计总容量为 2000 万 Token。它反映当前本机工作负载的样本比例；同一账号在其它设备同时使用时，未采集的活动会影响外推结果，不能当作官方固定容量。无需价格表、真实账单或手动导入请求日志。

## 使用

1. 在本机 Codex 登录自己的 ChatGPT 账号，打开 `/usage/accounts`，连接账号。
2. 在“账号设置与监控”中设置别名，选择采样间隔并启用。默认关闭，支持 5 分钟至 24 小时；本机当前登录源一次监控一个账号。
3. OS API 运行时自动采样，无需模型被唤醒，也不要求浏览器保持打开。可以随时暂停。

首次连接只建立当前时刻的零基线，不认领之前的日志。后续读取 `(上次采样时刻, 本次额度采样时刻]` 的增量；至少相距 5 分钟、已用比例增加超过 1 个百分点且 Token 增加，才显示预计量。按账号、额度桶、窗口时长、重置周期与本机绑定分别保存。窗口过期显示“待刷新”，不拿过期百分比当当前值。

## 数据与监控

新链路使用 `account/read` 和 `account/rateLimits/read` 核对前后账号，Token 改读 `CODEX_HOME`（默认 `~/.codex`）内 `sessions` 与 `archived_sessions` 的本地 JSONL，不再请求延迟的 `account/usage/read` 汇总。只接受明确 `model_provider=openai` 或已持久化 `thread_settings.model_provider_id=openai` 的活动，第三方网关与未知来源不混入。

有 `token_usage_record` 时按唯一 response ID 去重；旧日志才使用 `token_count` 的单次用量或累计差分。输入包含缓存，只加一次输出，不重复加 reasoning；父子继承、重复快照、归档副本不重复统计，无法确认的旧子日志会跳过。读取在异步工作线程中进行，有时间、字节和文件数上限；损坏、冲突、超限或未完成尾行会打断样本，不冒充成功的零。

账号、源目录或登录/配置文件的元数据 generation 改变时重建绑定。只读文件的 stat，不读凭据内容；采样期间发生变化则丢弃本机增量。累计样本与绑定起点随快照持久保存，API 重启可继续原区间。旧 `codex_account_activity` 汇总快照原样保留，仍返回 `activity_coverage_unknown`，不会混进新的 `codex_local_logs` 样本。独立模型额度桶不套用主账号总活动量。

暂停或改设置使在途采样失效；所有 API worker 与手动采样共用持久租约。额度与活动快照同事务保存，过期执行器不能写回。服务恢复后只执行一次到期采样，不补跑积压周期。切换登录账号或授权不可用会暂停旧绑定，网络失败按配置间隔重试。

## 安装与隔离

macOS 默认使用 Desktop 内置 `/Applications/ChatGPT.app/Contents/Resources/codex`；其它安装可显式配置 `AITEAM_CODEX_BINARY` 绝对路径。OS 不复制凭据、邮箱或原始账号 ID，只保存单向账号摘要与用户别名；不发起登录、切号或授权刷新。只读采样子进程有时间上限并在结束时回收。

本批新增一张 `account_plan_snapshots` 表，保留已有账号、额度、请求批次、请求去重及监控配置表。不删除历史样本。已有价格 API、批次 API 与 `aiteam account-usage export` CLI 独立保留，套餐页面不再提供价格/JSON 导入流程。

验证使用独立 SQLite 与临时 Dashboard 构建；没有更改共享数据库或 Claude 端。部署需将源码、API 与页面同批更新并另获授权。没有个人 heartbeat、模型定时唤醒或后台自动抓价。
